# 监控夜间光场自动锁定平台

本项目是一套基于 STM32F407VETx 的双轴光场跟踪平台。四路光敏电阻感知左右、上下光照差异，系统驱动两台无刷电机调整云台方向；触摸屏提供手动控制、自动模式、参数调节和运行状态显示。项目使用 FreeRTOS 分配采样、界面、状态管理和电机控制任务，并通过 W25Q64 保存用户参数、出厂参数及电机校准数据。

**主要功能：**

- 自动模式根据四路光照差计算双轴相对角度目标；光差进入设定停转范围时保持当前位置。
- 手动模式通过触摸屏方向键控制双轴速度，松开后保持当前位置。
- 两轴分别读取 AS5600 角度，执行电角度校准、位置环与速度环控制；检测到传感器或运动异常时停机并进入异常模式。
- 可在屏幕上调节九项运行参数，保存后立即生效；支持确认后恢复出厂设置、回归上一有效版本。
- 手动空闲或自动满足入睡条件时关闭背光并进入 MCU STOP 模式；触摸或 RTC 定时采光可唤醒系统。
- 参数记录带序号和 CRC32 校验。用户参数 A/B 双槽保留新旧两个版本，电机偏移量另有独立双槽。

## 软件运行流程

1. [main.c](Core/Src/main.c) 初始化时钟、GPIO、DMA、SPI、I2C、ADC、定时器和 RTC，先以关闭驱动使能的状态准备电机 PWM，再启动 FreeRTOS。
2. [freertos.c](Core/Src/freertos.c) 创建五个任务和三个长度为 16 的消息队列。各任务并行运行，系统状态任务负责模式切换、故障与低功耗。
3. 采样任务每 20 ms 从 ADC DMA 缓冲区取得四路值，经三点中值滤波和系数为 1/8 的一阶低通滤波，分别发送给 UI 和系统状态任务。
4. 系统状态任务使用最新光照、触摸事件和已生效参数产生电机命令；电机任务周期性读取编码器并更新两轴输出。
5. UI 任务独占 LVGL 对象操作，处理页面、按键、参数草稿、提示弹窗和光照数据显示。

| 任务入口 | 主要职责 |
| --- | --- |
| StartSmaplingTask | 启动 ADC DMA，滤波并发布四路采样。 |
| StartSystemStateTask | 管理手动、自动、异常模式，计算追光目标和 STOP 唤醒。 |
| StartMotorTask | 运行双轴位置/速度控制、校准和故障恢复检查。 |
| StartUiTask | 初始化并刷新 LVGL，处理触摸与弹窗。 |
| StartDebugTask | 当前仅周期性延时，未实现持续调试输出。 |

三条队列分别承载采样数据到 UI、采样数据到系统状态任务，以及系统状态任务到电机任务的双轴相对角度命令。队列满时，系统状态侧会优先保留新的光照或角度目标。

## 光照判断与自动跟踪

设四路滤波后的 ADC 值为左上 LT、左下 LB、右上 RT、右下 RB。系统计算：

- 左右差 = LT + LB − RT − RB。
- 上下差 = LT + RT − LB − RB。
- 平均值 = (LT + LB + RT + RB) / 4。
- 光照总差 = 四路最大值 − 四路最小值。

进入自动模式后先等待 3 秒。某一轴的光差绝对值没有超过该轴“最小差异”参数时，该轴维持当前位置；超过范围时，用光差乘以可调的自动 Kp 形成相对角度目标，目标绝对值限制为 360°。水平与垂直轴分别计算，命令经队列送至电机任务。四路滤波 ADC **全部大于 1500** 时，代码将两轴目标置零并保持位置。ADC 值与实际光照强弱的对应关系取决于本项目光敏电路；在当前判断中，较大的 ADC 均值被用于“偏暗”条件。

若超过 100 ms 没有新光照样本，自动追光停止并保持当前位置。屏幕底部持续显示四路读数及派生光差，自动页另外显示平均值和光照总差。

## 双轴无刷电机控制与异常恢复

[SimpleFOC_Motor.c](Core/interface/SimpleFOC_Motor.c) 将 TIM1 映射到垂直轴、TIM8 映射到水平轴。两轴各用一只 AS5600 测机械角，软件累计跨圈角度，结合已保存的电角零位进行 FOC 电压控制。首次需要校准时，使用 1.0 V 的 d 轴电压对齐 800 ms，然后把校准结果写入 W25Q64。校准记录包含格式标识、极对数及方向配置、两轴有效标志和电角偏移。

位置控制由“位置误差 → 目标角速度”的比例环和“速度误差 → q 轴电压”的 PI 环组成；手动方向键直接设置速度目标。当前代码中的主要控制常量如下：

| 常量 | 当前值 | 作用 |
| --- | --- | --- |
| 电机极对数 | 7 | 机械角转电角。 |
| 标称母线电压 | 12 V | FOC 电压计算基准。 |
| 位置 Kp | 2.5 | 将位置误差转换成速度目标。 |
| 速度 Kp / Ki | 0.18 / 4.47 | 生成 q 轴电压。 |
| 速度反馈滤波时间常数 | 0.02 s | 平滑编码器差分速度。 |
| 目标速度上限 | 180°/s | 软件速度指令上限，不代表机械保证转速。 |
| q 轴电压指令上限 | 5.5 V | 限制输出电压指令；不是电流限制。 |
| q 轴电压变化率上限 | 20 V/s | 限制指令突变。 |

本工程没有电流采样形成的电流环，不能把 q 轴电压上限理解成可直接设定的电机电流或扭矩。编码器、存储记录或运动状态触发故障后，系统停止电机并切换到异常模式。手动首页右上角出现“恢复电机”按钮：按下后在驱动关闭状态下重新核对 W25Q64 校准记录与两只 AS5600；检查通过则清除故障、回到手动模式并弹出“恢复成功，一切恢复正常”，失败则显示“保存失败”。此检查不包含带载试转，因此不能证明机械阻力已经消失。

## 触摸界面与九项参数

主界面使用纵向 Tileview 在手动/自动模式间切换。手动首页可进入“手动控制”“参数调节”“产品说明”和“手机 App 观测”。手动控制页按住上、下、左、右方向键运动，松手保持当前位置。产品说明页可预览异常提示；“手机 App 观测”当前只有页面入口和返回按钮，没有手机通信或观测数据功能。

参数页使用横向 Tileview，共两页，第一页五项、第二页四项，角落显示 1/2 或 2/2。亮度用滑块，其余八项用加减按钮，支持长按连续加减，范围边界不会越界。“保存”“恢复出厂设置”“回归旧版本”三个按钮固定在瓦片外。修改参数先进入草稿，保存成功并从 Flash 读回后才成为运行时参数；离开未保存页面时会弹窗询问。恢复出厂或回归旧版必须先确认，成功后当场保存并生效，无需重启。

| 参数 | 出厂默认值 | 可调范围 | 作用 |
| --- | ---: | ---: | --- |
| 亮度调节 | 100% | 30–100% | 屏幕背光 PWM 占空比。 |
| 手动熄屏时间 | 20 s | 10–100 s | 手动模式无触摸且未持续运动后的熄屏/入睡时间。 |
| 自动熄屏时间 | 15 s | 10–100 s | 自动模式熄屏时间，也用于满足自动入睡条件的连续等待时间。 |
| 左右光最小差异 | 50 | 0–100 | 水平轴光差停转范围，单位为 ADC 差值。 |
| 上下光最小差异 | 100 | 0–200 | 垂直轴光差停转范围，单位为 ADC 差值。 |
| 低功耗光强阈值 | 1800 | 0–4095 | 四路 ADC 平均值大于该值时满足偏暗入睡条件。 |
| 自动唤醒读光时间 | 5 s | 3–100 s | 自动 STOP 期间 RTC 定时采光间隔。 |
| 手动基础速度 | 60°/s | 1–180°/s | 手动按键下发的目标速度。 |
| 自动 Kp | 0.12 | 0.01–1.00，步进 0.01 | 光差到相对角度目标的比例系数。 |

系统以九个 uint16_t 按表中顺序保存用户参数。参数的有效范围由同一组范围表同时供界面和保存校验使用。

## 熄屏、STOP 与唤醒

手动模式在无触摸、未按住方向键且达到设定时间后关屏并进入 STOP。自动模式有两项入睡判据：**两轴光差都落入各自停转范围**，或者**四路 ADC 平均值大于低功耗光强阈值**。进入自动模式后的最初 3 秒不累计；其后任一条件在新鲜采样下连续满足自动熄屏时间，才进入 STOP。

屏幕熄灭前 5 秒，背光降至当前设定亮度的 30%。触摸屏中断可唤醒并点亮屏幕，第一次唤醒手势被屏蔽以免误触按钮。自动 STOP 中，RTC 按设定间隔短暂唤醒 ADC 采光：如果入睡条件仍成立，就继续 STOP；如果两项都不成立，恢复采样与追光，但保持黑屏。退出 STOP 时重新配置系统时钟，并用 RTC 经过时间补偿 RTOS 节拍。

## W25Q64 参数存储与断电处理

[W25Q64.c](Core/interface/W25Q64.c) 用 SPI2 DMA 读写 W25Q64，检查 JEDEC ID；页编程以 256 字节为单位，擦除以 4 KiB 扇区为单位。芯片末尾五个 4 KiB 扇区固定分配：

| 地址 | 用途 |
| --- | --- |
| 0x7FB000 | 用户参数 A：新版/旧版轮换。 |
| 0x7FC000 | 用户参数 B：新版/旧版轮换。 |
| 0x7FD000 | 出厂参数：独立保存固件默认值。 |
| 0x7FE000 | 电机电角偏移 A。 |
| 0x7FF000 | 电机电角偏移 B。 |

每条记录以 16 字节记录头开始，依次是 4 字节标识、4 字节递增序号、4 字节载荷长度、4 字节 CRC32；其后是实际数据。读取时核对记录头、长度和 CRC，再按序号选择有效最新版。保存时，如果内容与最新版相同则跳过擦写；内容变化时，只擦写较旧或无效槽，保留另一槽的上一份完整记录。第一次保存用户参数只写 A，旧版必须等到第二次不同内容成功保存后才存在。

上电时先检查 Flash，然后核对出厂扇区与固件内置默认值；只有内容变化或出厂记录损坏时才重写。用户 A/B 有有效记录时加载最新版本；两槽均无效时，运行时保留代码内置默认值。恢复出厂设置会把出厂扇区的参数作为**新用户版本**保存，因此原有效用户版本仍可供“回归旧版本”读取。回归旧版则把旧槽内容重新保存为最新版本。保存到一半断电时，若另一槽保留完整有效记录，下次启动仍可加载它；代码依据记录校验判定，不把未完成写入当作有效版本。

芯片前部区域有原始读取、编程和擦除接口，写入接口明确禁止覆盖以上五个参数扇区；当前工程没有实现固件 OTA 升级流程。
