- 在仓库根目录新建 `.gitignore`，共 8 个分区 + 1 个保留清单：

  4. STM32CubeMX：忽略 `.mxproject`（本机库缓存），保留 `.ioc`。
  5. OS 垃圾文件（Windows/macOS/Linux）。
  6. Office 临时锁文件 `~$*.docx` 等（word/ 下文档本体必须提交）。
  7. 日志与 core dump。
  8. Python 缓存（预留）。
  9. 文末显式 `!` 保留清单，防止通配规则误伤 `.ioc / CMakeLists.txt / CMakePresets.json / *.ld / *.s / cmake/*.cmake / cmake/stm32cubemx/CMakeLists.txt`。
