# 太阳能追光系统文档说明

## 已完成任务

产品方案已经完善，已明确以下内容：

- 自动模式、手动模式、异常模式及低功耗运行状态。
- 自动追光、光照不足、明亮模式、暗淡模式和低功耗处理逻辑。
- 自动模式进入时 3 秒数据稳定倒计时。
- 四路 ADC 总差异的判断方式及追光阈值逻辑。
- 手动模式下长按方向按钮控制电机，松开后立即停止。
- 模式切换、页面返回、页面状态保留和参数草稿处理。
- 参数保存时停止电机、写入 W25Q64、保存成功与失败处理。
- 异常传感器检测、异常标志位、异常模式和异常窗口处理。
- 产品结构、FOC、电源、机械结构及后期改进方向。

产品方案正文见 [Product_Plan/product_plan.md](Product_Plan/product_plan.md)。

## 未完成任务

技术实现方案文档还没开始做，后续需要进一步明确和编写：

- FreeRTOS 任务、优先级、周期和任务间通信。
- 系统状态机、模式枚举、停止电机标志位及异常锁存机制。
- ADC 四通道采样、DMA、滤波和数据有效性判断。
- 电机控制、FOC、PWM、PID/LQR 及方向控制接口。
- W25Q64 双记录、CRC32、断电恢复和保存事务流程。
- LVGL 页面、回调、页面栈和参数草稿状态管理。
- 低功耗、唤醒、传感器异常检测和复位流程的代码实现。
- 联调、边界条件测试和整机验证方案。
