第 7 章 · 定时器 PWM 硬件基础（tim.c）——电机三相 PWM 与背光 PWM 的来源

文件：Core/Src/tim.c（392 行）

本章导读

三个定时器各司其职：TIM1/TIM8（高级定时器）各输出三路互补通道 PWM，是双轴 FOC 的三相逆变桥驱动；TIM3_CH4 输出背光 PWM（0~100% 调亮度）。本章逐行讲解配置，并在小总结里算清 25kHz 电机 PWM 与 1kHz 背光 PWM 的频率来历，以及 ARR/CCR 与占空比的关系（这是看懂 SVPWM 写比较值的前提）。

小总结（TIM1 配置）：本段代码完成的工作是把竖直轴的三相“逆变器”配好：168MHz 不分频、ARR=6719 → 25kHz PWM；三个通道 PWM 模式 1、极性高、初始 CCR=0（0% 占空比）。原理：高级定时器 TIM1/TIM8 的 CH1/2/3 将来由 SVPWM 算法写入不同 CCR，三个通道输出三路相位/占空比可独立调节的方波，接到电调三相输入就等效于施加三相对称电压；刹车/死区虽未启用，但空闲态输出低、自动输出关闭保证了配置期间引脚安全。

本文件小总结

tim.c 全文总结：TIM1/TIM8 = 25kHz 三相 PWM（ARR 6720、CCR∈[0,6720] 对应 0~100% 占空比），是 SVPWM 输出的硬件载体；TIM3_CH4 = 1kHz 背光 PWM（CCR 0~100 即亮度百分比）。频率计算公式：f = 定时器时钟 / (PSC+1) / (ARR+1)。SimpleFOC_Motor.c 里 __HAL_TIM_GET_AUTORELOAD 读回 6719、period=6720，占空比 duty×period 即为要写的 CCR——两章对照看。

本章总结

本章总结：PWM 三要素：时钟(PSC+1 分频)→计数周期(ARR+1)→比较值(CCR)。电机 25kHz（听不见、电流纹波小），背光 1kHz（省电且无频闪感）。SVPWM 模块最终做的只是“算出三个 0~1 的占空比 → 乘 period 写入三个 CCR”。
