# 思路：

## 光敏电阻：

### 1-1光敏电阻位置

4个光敏电阻分别放在左上角，左下角，右上角，右下角，通过ADC转换数值判断光照强度方向从而平衡上下左右位置，ADC转换的数值可以通过卡尔曼滤波得到（设计初先用低通滤波，待功能完善全部设计都稳定之后再用卡尔曼滤波，或者AI帮我思考一下该用什么滤波）

### 1-2隔板问题

光敏电阻模块之间要拿隔板隔开，这样更能检测环境中光的实际位置（离得远就被挡板挡住了）

### 1-3低功耗退出和进入

自动模式：设置光照最低阈值、光照唤醒阈值和光照最小差异值。光照唤醒阈值必须高于光照最低阈值，二者构成光照强度判断的滞回区间：光照最低阈值作为自动模式的停止阈值，平均光照强度低于或等于该阈值时，自动模式停止追光并进入暗淡/低光倒计时逻辑；光照唤醒阈值作为启动阈值，平均光照强度达到或高于该阈值时，低功耗状态允许被光照唤醒。光照最小差异值只用于判断方向差异是否足够大，不参与低功耗唤醒判断。

其中，光照最低阈值用于自动模式的停止判断，光照唤醒阈值用于低功耗的光照唤醒判断，光照最小差异值用于方向差异判断。三者的判断对象不同，不能互相替代；光照唤醒阈值必须高于光照最低阈值。

先通过实际测试确定阈值：例如使用手机电筒在距离光敏电阻 1 m 处照射，记录四路 ADC 值并计算平均光照强度，作为参数设置的参考。

自动模式下，若平均光照强度持续 15 s 低于或等于光照最低阈值，则停止自动追光并进入低光倒计时；倒计时内若平均光照强度恢复到高于光照最低阈值，或用户切换到手动模式，则取消低光倒计时。倒计时结束后进入低功耗，低功耗时不显示底部实时数据。

低功耗模式下，当平均光照强度达到光照唤醒阈值或用户触摸唤醒时退出低功耗。唤醒后恢复进入低功耗前的页面和模式：若恢复到自动模式，立即按自动模式优先级重新判断；若恢复到手动模式，保持电机停止并等待新的手动方向命令。低功耗期间不弹出传感器异常窗口；退出低功耗后重新开始异常持续时间计时。

### 1-3-1 异常检测与异常模式

异常检测只在非低功耗状态下进行，包括自动模式进入的 3 s 倒计时期间。以滤波后的四路 ADC 数据为判断对象：若某一路连续为 0 或 ADC 满量程最大值超过 2 s，且其余传感器并非全部处于 0 或满量程（即至少一路处于 0 与满量程之间的正常范围），则判定为传感器异常；“连续超过 2 s”表示异常条件在整个计时期间都必须保持，期间只要该路恢复到正常范围，或其余传感器不再满足组合条件，就立即清零本次异常计时，重新开始判断。四路全部为 0 或全部为满量程时，暂不按本规则判定单路异常。一旦判定异常，立即取消自动模式进入倒计时、低光倒计时和电机输出，然后进入异常模式。

进入异常模式后设置异常标志位并锁存，停止所有电机；自动追光、手动方向控制和其他可能启动电机的命令全部无效。系统只在首次进入异常模式时请求弹出一次设备异常窗口，窗口允许关闭，但关闭窗口不能清除异常标志位。异常模式只能通过复位单片机退出。

手动模式：

手动模式不因无操作自动进入低功耗；具体页面和控制规则参考第 4 节“UI界面设计”。

### 1-4最低差异值（阈值）

设置一个光照最小差异值，用于判断光照方向是否仍需要调整。该参数不等同于光照最低阈值或光照唤醒阈值。

总差异 = 四个 ADC 值中的最大值 - 最小值。

当总差异不高于最低差异值时，说明四路光照接近平衡，保持当前位置，不驱动电机；当总差异高于最低差异值时，才允许自动追光。

### 1-5机械结构

长方形模板，留出一段长用于光敏电阻放置，记得要打孔穿光敏电阻进来，光敏电阻之间用隔板隔开，用热熔胶加冰棍棒加打孔固定住模块

### 2-0 双轴闭环电机映射

当前双轴电机方案已经确认使用两个 AS5600 磁编码器作为转子位置反馈，电机不是无位置反馈的开环控制：

| 轴 | PWM 定时器 | AS5600 通信接口 | 闭环反馈 |
| --- | --- | --- | --- |
| 上下轴 | TIM1 三路 PWM | I2C1 | 读取 AS5600 转子机械角度，参与电角度计算和闭环控制 |
| 左右轴 | TIM8 三路 PWM | I2C3 | 读取 AS5600 转子机械角度，参与电角度计算和闭环控制 |

三路 PWM 分别连接对应电调的三相控制输入，AS5600 不通过 PWM 返回数据，而是通过独立的 I2C 总线提供角度反馈。两个 AS5600 即使都使用默认地址 `0x36`，也因位于不同 I2C 总线上而不会冲突。控制器读取角度反馈后更新对应电机的 PWM 控制量，形成两路独立的转子位置反馈闭环。

当前已确认的双轴电机参数如下：

| 项目 | 上下轴 | 左右轴 |
| --- | --- | --- |
| PWM 定时器 | TIM1 | TIM8 |
| PWM 引脚 | PE9 / PE11 / PE13 | PC6 / PC7 / PC8 |
| EN 引脚 | PE7，高电平有效 | PE8，高电平有效 |
| 位置反馈 | I2C1 + AS5600 | I2C3 + AS5600 |
| 电机供电 | 12 V | 12 V |
| 极对数 | 7 | 7 |
| PWM 预分频 | 0 | 0 |
| PWM 模式 | PWM1 | PWM1 |
| PWM 有效电平 | 高电平 | 高电平 |
| PWM 周期 | 11200 - 1 | 11200 - 1 |
| PWM 频率 | 约 15 kHz | 约 15 kHz |

两轴均为 AS5600 位置反馈闭环。后续实机需要校准 AS5600 磁铁安装同心度、零位、旋转方向、停止安全值和机械限位；这些属于闭环运行参数校准，不是是否采用闭环的待定项。当前驱动代码是基于位置反馈的电压换相控制，若后续需要完整电流环 FOC，还需要增加相电流采样和相应保护。

## Flash存储参数

### 3-1双备份存储+数据包

用于存储参数调节值，每次上电后取上次保存的值出来，如果flash不够用就可以外接W25Q64，采用双备份

双备份就是把同一份参数保存两次，放在两个独立存储区：Record A 和 Record B。目的不是备份得漂亮，而是防止保存过程中掉电后两份都坏。

每条记录建议包含：

magic       固定标识，判断是否为本系统参数

version     参数结构版本

sequence    保存序号，越大代表越新（！！！！！加超范围判断）

length      参数数据长度

payload     参数本体（有多个参数，封装全部参数成结构体进行运输）

crc32       对前面参数数据的校验值

commit      最后写入的有效标志

### 3-2上电读取流程

1. 分别读取 A、B。

2. 检查 magic、version、length、commit 和 crc32。

3. 两条都有效：使用 sequence 更大的那条。

4. 只有一条有效：使用有效条。

5. 两条都无效：加载编译时默认参数（需要代码里面预留一份默认参数），并提示参数未初始化或已恢复默认值。流程是先读取代码里面的默认参数，再读取W25Q64里面保存的参数，若读取异常（两条都无效），那么就不读取，保留代码内的默认参数作为当前参数

### 3-3保存流程

假设当前 A 有效且最新，则写 B：

保存流程由 SystemStateTask 和 FlashTask 协同完成：

1. 用户点击“保存”后，SystemStateTask 立即置位停止电机标志位，并清除所有手动方向命令，确认电机停止；保存成功或失败前，电机都不得重新启动。

2. 复制一份完整的待保存参数快照。参数页面中的草稿参数在保存完成前不改变当前生效参数。

3. 擦除 B 所在扇区。

4. 写入 B 的头部、参数 payload、crc32，但不写 commit。

5. 回读 B，重新计算 CRC，确认数据完整；确认无误后最后单独写入 commit 有效标志。

6. B 从此成为最新记录；A 保留，不立即擦除。

若写入过程中掉电，B 因缺少有效 commit 或 CRC 错误而被判为无效（读取时直接忽略）；下次启动仍加载旧的 A。只有保存成功后，新的参数才允许参与自动模式或手动模式的后续逻辑。

7. 保存成功：将待保存参数提交为当前生效参数，清除页面草稿状态并显示“保存成功”。保存成功后，系统仍保持本次保存流程设置的停止电机标志位，并按当前模式重新计算是否允许输出：若当前为自动模式，只有自动模式 3 s 倒计时已结束、光照强度和总差异满足追光条件且无异常时，才允许电机重新追光；若当前为手动模式，必须等待用户重新按下有效方向按钮后才允许电机运动；若当前为异常模式或低功耗状态，电机继续保持停止。保存失败：丢弃待保存参数，恢复保存前的旧参数，保持停止电机标志位有效，并显示“保存失败”。保存失败后电机保持停止，用户可重试保存或重新进入其他页面。

### 3-4关键细节

- commit 必须最后写，不能和其他字段一起写。

- 不要在新记录确认有效后立刻擦掉旧记录。

- A、B 应位于两个独立 Flash 扇区；W25Q64 可各占一个 4 KB 扇区。

- sequence 每保存一次加 1，用于判断最新记录。

- STM32内部Flash擦除时间较长，FlashTask应为低优先级

## UI界面设计

这个需求最适合做成多个独立页面：

使用 LVGL 的 tileview（瓦片视图）设计手动模式页面和自动模式页面切换。系统模式枚举只有三个值：手动模式、自动模式、异常模式；低功耗是独立的运行状态，不作为第四个模式枚举。进入参数调节、产品说明或手机 App 等子页面时，不修改模式枚举。

上电默认显示手动模式页面，自动模式页面位于手动模式页面下方，用户可通过上下滑动切换。若上电读取到异常状态不成立，则初始模式为手动模式；异常模式只能在运行过程中触发，或由复位后的检测重新判定。

系统始终根据当前模式枚举无阻塞执行对应逻辑：手动模式只处理手动控制，自动模式只处理自动追光，异常模式执行停止所有电机的逻辑。异常模式优先级最高，任何页面切换、低功耗请求、参数保存和手动/自动命令都不能清除异常标志位或重新启动电机。

1-1：手动模式页面分布的第一个按钮：手动控制

进入手动控制页面，显示上、下、左、右四个方向按钮。按下某一方向按钮时记录对应的手动方向命令，在按键持续按住期间电机按设定的手动基础速度连续移动；松开按键的一瞬间立即清除该方向命令并停止电机。手动方向按键在异常模式或停止电机标志位有效时无效；只有非异常状态下重新按下方向键时，才允许清除模式切换产生的停止标志。右上角返回按钮返回进入本页面前的上一页面。

1-2：手动模式页面分布的第二个按钮：参数调节

可调节参数包括：光照最小差异值、光照唤醒阈值、光照最低阈值、手动模式电机基础速度、自动模式电机基础速度。光照唤醒阈值是低功耗光照唤醒的启动阈值，光照最低阈值是自动模式停止追光并进入暗淡/低光逻辑的停止阈值；二者必须满足“光照唤醒阈值 > 光照最低阈值”。光照最小差异值只用于总差异判断：总差异 = 四路 ADC 最大值 - 最小值，平均光照强度高于光照最低阈值且总差异高于光照最小差异值时才允许自动追光。每个参数必须在代码中设置最小值和最大值：超过最大值时改为最大值，低于最小值时改为最小值。实际取值范围需要结合实测环境确定，后续 AI 协助实现或调参时，必须先提醒用户提供这五项参数的明确取值范围，再进行代码实现。若修改后不满足“光照唤醒阈值 > 光照最低阈值”，保存校验失败，恢复旧参数并保持电机停止。

参数修改后，只有点击当前页面的“保存”按钮才正式提交。点击保存时先停止电机，再按第 3 节流程写入 W25Q64；保存成功后新参数正式生效并显示成功提示，保存失败时恢复旧参数、保持电机停止并显示失败提示。参数页面应同时维护“当前生效参数”和“页面草稿参数”。从参数调节页面普通点击“返回”时，若存在未保存修改，弹出“是否保存修改”：点击“保存”执行保存流程，点击“放弃”恢复进入本页面前的参数并清除草稿，点击“取消”留在当前页面继续修改。若用户是通过切换模式或进入低功耗离开参数页面，则不弹出保存提示、不自动保存，只保留页面草稿和页面状态；下次返回手动模式的参数调节页面时，仍显示原来的未保存修改，可以继续修改或点击保存。复位单片机或保存成功后，草稿状态清除。手动模式的非低功耗页面可显示“进入低功耗模式”按钮，点击后立即停止电机并进入低功耗；低功耗时屏幕黑屏，触摸屏点击可唤醒。参数页面不应因模式切换或进入低功耗而销毁，应保留进入页面时的参数快照、草稿参数、是否有未保存修改的标志以及页面返回栈位置。

点击进入后显示产品说明文字，右上角返回按钮返回进入本页面前的上一页面。

1-4：手动模式页面分布的第四个按钮：手机App观测

该功能进入空白页面（待开发），右上角返回按钮返回进入本页面前的上一页面。

自动模式页面显示当前自动状态：进入自动模式倒计时、明亮模式、暗淡模式、光照不足倒计时或低功耗。每次进入自动模式页面或从手动模式切换到自动模式时，先进行 3 s 倒计时；倒计时期间允许采集和显示光照数据，但电机禁止动作。页面显示平均光照强度、总差异、当前状态和倒计时。

自动模式按以下优先级执行：进入自动模式的 3 s 倒计时期间，允许采集数据但禁止电机动作；倒计时结束后，1. 若平均光照强度低于或等于光照最低阈值，进入暗淡模式，停止追光并开始 15 s 低光倒计时，倒计时结束后进入低功耗；2. 若平均光照强度高于光照最低阈值且总差异不高于光照最小差异值，进入明亮模式并保持当前位置；3. 若平均光照强度高于光照最低阈值且总差异高于光照最小差异值，进入明亮模式并自动追光。这里的“总差异”始终定义为四路 ADC 最大值减最小值，只有总差异高于光照最小差异值才允许追光；光照唤醒阈值不用于替代光照最小差异值。低光倒计时期间，平均光照强度恢复到高于光照最低阈值时取消倒计时，并重新按上述优先级判断；切换到手动模式时也必须取消低光倒计时。异常模式的判断优先于以上全部逻辑。

低功耗状态下，屏幕黑屏，底部实时数据显示隐藏，电机保持停止；等待平均光照强度达到或高于光照唤醒阈值，或用户触摸唤醒。唤醒后恢复进入低功耗前的页面和模式，并保留页面草稿和页面状态。若之前是自动模式，光照唤醒或触摸唤醒后立即按自动模式优先级重新判断：平均光照强度高于光照最低阈值且总差异高于光照最小差异值时恢复自动追光；如果平均光照强度不高于光照最低阈值，则保持暗淡模式并继续低光倒计时；如果平均光照强度高于最低阈值但总差异不高于最小差异值，则进入明亮模式并保持当前位置。这里的“立即”表示唤醒后立即开始判断，不绕过异常检测、停止电机标志位和自动模式条件检查。若之前是手动模式，则保持手动模式且电机停止，等待新的手动方向命令。低功耗期间不弹出异常窗口；异常模式不允许进入低功耗，若系统在进入低功耗前已经处于异常模式，则仍保持异常模式，不能通过唤醒退出异常。

模式、页面与低功耗事件规则：

1. 切换到自动模式：回调函数先清除所有手动方向命令并置位停止电机标志位；再把模式枚举改为自动模式；最后启动 3 s 自动模式进入倒计时。倒计时期间可以采集和显示光照数据，但不允许电机输出；倒计时结束后按自动模式优先级判断。只有平均光照强度高于光照最低阈值且总差异高于光照最小差异值时，才允许自动追光。

2. 切换到手动模式：回调函数先清除所有手动方向命令并置位停止电机标志位；再取消自动模式的 3 s 倒计时和 15 s 低光倒计时；再把模式枚举改为手动模式。保存流程结束后或切换完成后，电机仍保持停止，直到用户重新按下方向按钮；不能因为参数保存成功就自动恢复上一次手动方向。异常标志已置位时，模式枚举保持异常模式，不允许切换为手动或自动模式。

3. 系统始终以模式枚举为准：当前模式是哪一个，就只执行该模式对应的逻辑。异常模式拥有最高优先级，停止电机标志位有效时，任何模式的电机输出都无效。

4. 所有“返回”按钮均返回进入当前页面前的上一页面；页面允许层层嵌套并连续返回。普通子页面返回不修改模式枚举，也不自动保存页面草稿。

5. 手动控制页面返回时立即清除手动方向命令并停止电机；自动模式页面切换为手动模式时也必须先清除手动方向命令并停止电机，再修改模式枚举。保存参数、切换模式、进入低功耗和进入异常模式都可以让 SystemStateTask 设置同一个停止电机标志位。该标志位不由 UI 回调直接清除，而是由 SystemStateTask 每次根据当前状态重新计算：异常模式、低功耗、保存过程、自动模式 3 s 倒计时未结束、低光倒计时未结束或手动方向命令未有效时，停止标志为 1；在非异常、非低功耗、保存已结束、倒计时已结束且自动模式满足追光条件，或手动模式下收到有效方向指令时，才将停止标志重新计算为 0。这样只需一个停止标志位，也不会因为某一个事件单独清除标志而误启动电机。

在非低功耗状态下，所有页面底部持续显示四个光敏电阻实时值、平均光照强度和总差异，不受普通页面切换影响；进入低功耗后屏幕黑屏，同时隐藏底部实时数据，不再显示这些内容。自动模式下：平均光照强度低于或等于最低阈值时显示“光照不足，%d 秒后进入低功耗模式”；平均光照强度高于最低阈值且总差异不高于光照最小差异值时显示“明亮模式，当前位置保持”；平均光照强度高于最低阈值且总差异高于光照最小差异值时显示“明亮模式，自动追光中”。异常模式下显示设备异常状态，但不重复创建异常窗口。

异常模式页面与窗口规则：异常模式不要求单独替换当前页面，手动模式页面或自动模式页面均可继续显示，但所有电机启动入口必须失效。首次进入异常模式时只发送一次“设备异常”窗口请求，必须使用一次性的弹窗请求标志防止每个循环重复创建窗口。窗口可通过叉号关闭，关闭后仍可以进入产品说明、参数调节和保存流程，但不能清除异常标志。异常模式不能通过返回按钮、切换页面、进入低功耗或保存参数退出，只有复位单片机后异常标志才清除。
